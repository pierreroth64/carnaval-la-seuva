# 🎪 Carnaval de la Forêt — Version avec Logo Arbre 🌳

Dans cette version, l'icône du titre principal est désormais un **arbre feuillu** (🌳).

## Caractéristiques
- **Logo d'en-tête** : Arbre festif (🌳) au lieu du blaireau.
- **Croix Occitane (SVG)** : Conservée pour le bouton de sélection linguistique `OC`.
- **Éditorial persistant** : Dépliable/repliable (`content/edito.md`) en haut de page.
- **Vignettes Markdown** : Gérées dans `content/vignettes/`.

## Commandes
```bash
npm install
npm run build   # Génère _site/index.html
npm run start   # Serveur de développement avec rechargement à chaud
```
