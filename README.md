# 🌿 Carnaval de La Seuva

Site statique facilement hébergeable pour le Carnaval de Lasseube 2027.

## Structure
- `content/edito.md` : Article d'en-tête persistant et dépliable.
- `content/vignettes/` : Les fiches individuelles en Markdown.
- `content/index.njk` : template compilé par Eleventy.

## Commandes
1. `npm install` (installation initiale)
2. `npm run build` (génère `_site/index.html`)
3. `npm run start` (serveur local)
